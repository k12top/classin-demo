# Activity choices, released results and class-end discoverability

The teacher's answer chart previously showed only option letters/counts; text was available only in a hover title. Ending an activity only closed responses. The separate release action was buried in teacher-only reasoning, so students saw an ended question with no correctness feedback. Class end was available in the lesson-clock menu, but absent from the course menu; the overtime exit dialog offered only conditional last-teacher departure.

The teacher chart now shows the complete option text, letter and count in wrapping rows on desktop and mobile. Published student feedback explicitly shows correct/incorrect/partial/pending/unanswered status, submitted answer, correct answer and score. Correct options and selected wrong options have distinct styling and text/icon feedback. Unsaved edits cannot replace the submitted answer when results are shown.

A teacher's explicit **end responses** command atomically publishes fully graded objective quizzes. Before that command, student snapshots still exclude keys, grades and other students' submissions. Written/mixed activities remain closed for teacher confirmation; the release-results action is visible outside the reasoning accordion. Previously closed activities, timeouts and replacement closures retain their existing publication gate: teachers can use the visible release action when ready. AI review is not silently published. Student panels open once when results transition to published, including for students who did not submit.

Class end is now directly available in the course-name menu as well as the existing clock menu. During overtime, the exit dialog also offers **end class and stop recording**, followed by the existing full-class confirmation. Temporary leave and the existing last-teacher-only departure remain separate choices. Opening the confirmation does not end a lesson; final navigation still waits for the durable server acknowledgment.

Validation uses disposable PostgreSQL, actual React components and isolated Chromium windows. It covers pre-release privacy, objective close/retry, late-answer rejection, pending written reviews, complete option text on narrow screens, wrong/correct/unanswered feedback, unsaved-edit preservation, course-menu access, overtime explicit end, confirmation and acknowledgment before navigation. No active production lesson or question was ended or published for verification. There is no schema migration.
