## 本轮落实

- 新增 `src/lib/use-workspace-courses.ts`，首页和 `WorkspaceSubpage` 共同使用。复用既有调度器的退避与请求合并，不增加额外的轮询系统或更改课堂媒体。
- 保留现有设计与空状态；只修正数据读取、失败恢复、卸载取消与账号边界。网页通过可取消 HTTP 获取课程；Electron 首页仍通过现有受限 IPC 读取加密缓存。
- 新增 `tests/integration/workspace-course-recovery-ui.cjs`：实际页面、React hooks 和 HTTP 读取；身份、课程内容、页面壳展示和桌面 IPC 返回是测试夹具。修复前在“首次 503 后自动恢复”断言失败。最终检查记录见 [课程读取恢复验证](../../clients/desktop/verification/workspace-course-recovery/README.md)。

## 建议顺序

1. 真实录制/字幕/互动回放已完成本轮隔离环境验收；保留首次启动失败的 provider 退出核对记录，后续上线时按实际部署 SHA 再验证。
2. 扩展桌面聊天离线持久化，解决关闭窗口后草稿和未确认消息的恢复；同时准备正式发行与升级。
3. 补足真实账号写入/失败恢复记录和自动验收入口，再进行分支集成与部署核验。
4. 有第二台设备后完成远控、Windows 和真实媒体弱网验收；消息正文检索/附件作为独立增强排期。
