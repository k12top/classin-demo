# 课堂举手

交互课堂的学生可举手或取消举手，无论是否已在台上。ClassIn 桌面布局的入口在顶部控制区；手机入口在底部主要按钮中。老师及获授权的助教有同位置的举手列表，显示在线学生并按首次举手时间排序。台下学生可邀请上台，已在台上且未获发言权限的学生可允许发言。允许发言只授予权限，学生仍需自己打开麦克风。学生取消、接受上台邀请或主动退出会清除举手状态。

已在台上的学生举手时，视频格顶部显示常驻的举手图标，桌面和触摸屏都无需悬停。顶部座位、视频网格、主舞台及放到白板上的摄像头使用同一成员状态；关闭摄像头的座位也保留标识。取消举手或离开台上后图标消失，复用现有信道更新，不另开信道。

请求沿用 `POST /api/sessions/{sessionId}/classroom/actions`，学生端发送 `raiseHand` / `lowerHand` 及 `compactHandRaise: true`。服务端从登录会话确定本人，校验当前课次、模式、注册连接及有效期，在事务中保存 `ClassroomMemberState.handRaisedAt` 并返回 `handRaise` 消息。相同状态的重试保留首次时间和版本，不重复排队。

Redis 心跳可补充已注册连接的在线时间，避免 PostgreSQL 尚未批量同步时误判离线；已经在 PostgreSQL 关闭的连接不能被缓存重新授权。

确认成功后，通过现有 Agora RTM 课堂信道广播 `hand-raise` 消息：`courseId` 为课次 ID，包含 `actorId`、`revision` 与 `handRaisedAt`（取消为 `null`）。接收端用 RTM 的真实 publisher 与当前成员的连接身份匹配，只允许学生修改自己的举手状态，立即更新列表，并用权威状态刷新恢复丢包。记录每位学生已处理的消息版本，忽略重复和乱序消息。学生消息不推进课堂控制版本，不改变上台、摄像头或麦克风权限。信道不可用时沿用状态刷新恢复。

复用已有举手字段，本次无需新增数据库迁移。公开直播仍沿用不举手的模式约束。

验证：`tests/classroom-hand-raise.test.ts` 覆盖即时更新、本人身份、乱序与权限边界、队列排序及请求重试；`tests/integration/classroom-hand-raise.cjs` 使用隔离的回环 PostgreSQL `classroom_hands_*`，验证真实 API、事务、连接校验、上台与离开，以及真实 Agora 客户端适配器在模拟 RTM 传输上的收发。浏览器使用真实 React 控件、请求与信道适配器，在模拟 SDK/接口边界上验证老师和学生的两页交互、桌面及手机布局、取消与失败重试。真实 Agora 服务和线上课堂尚未实测。
