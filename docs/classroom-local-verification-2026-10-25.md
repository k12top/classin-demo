## 本次发现并修复

1. **下课后无法查看题目记录**：活动接口误用课堂准入时间限制。活动访问现在单独验证精确课次、当前名单与分享权限；活动服务仍限制答题、发布等操作。普通入会及图片访问没有获得活动回看的豁免。实际下课→题目回看→重开流程复验通过，补充登录、名单撤销、缓存隔离和取消课次检查。
2. **未开课显示上课中**：顶部计时将排期课程对象展开到运行状态之后，覆盖了 `runtime.status`。改为显式传递时间字段和运行状态，并用实际 Header 渲染回归测试防止覆盖。
3. **重连持续报 RTM -10027**：当前安装的 RTM SDK 构造器永久保留 app/user 配对；退出后重新构造仍报重复身份。现在按 SDK 构造器和 app/user 复用客户端，串行完成旧登录、退订、退出和新登录，清理旧监听器并隔离过期回调。补充模拟该 SDK 限制及延迟登录/退出的回归检查；本地生产模式的实际凭证刷新/恢复后未再出现该错误。
