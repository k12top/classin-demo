# 课堂顶部与交流侧栏

模式：Operate。保留现有浅色／深色课堂主题、相同教学能力和权限。

适用面为默认 V3 ClassIn 布局；V2 和显式启用的 legacy 布局没有纳入本次响应式视觉验收。

## 顶部按可用空间逐步收起

| 尺寸 | 顶部行为 |
| --- | --- |
| 超宽，≥1600px | 课程标题、计时、字幕入口、连接状态、聊天／字幕、教学控制和个人设置完整展示 |
| 宽，1280–1599px | 字幕外观进入更多；1440px 以下继续收起主题、语言和录制快捷键 |
| 紧凑，640–1279px | 聊天／字幕保留带无障碍名称的图标，收起计时和离开快捷键；1024px 以下音视频控制放到底部 |
| 很窄，320–639px | 课程标题单行截断，开课／结束使用带明确无障碍名称的图标；设置、字幕、录制、恢复、离开和语言从更多进入 |

开课／结束与离开仍是不同动作。开课和结束文本不再被固定宽度按钮挤压；结束课程继续使用已有确认流程。标题保留完整 `title`，菜单通过 Portal 呈现，不会被顶部裁切。

## 聊天／同传共用侧栏

依据用户选择，共用一列，顶部切换聊天与字幕，关闭按钮始终可见。方向键切换标签；切换时保留聊天草稿、翻译设置和阅读位置。

- 桌面：侧栏宽 320–400px，参与布局并挤压舞台，工具栏跟随舞台右缘。
- 手机／平板竖屏：底部面板覆盖下部区域，最高约 58dvh，保留原视频宽高；键盘弹出时根据 VisualViewport 避让。
- ≥640px 的手机横屏：使用 300px 右侧栏；字幕控制压缩为一行，聊天管理及翻译进入紧凑控制。
- 其他管理面板保留原有行为。点击舞台不会关闭聊天或字幕侧栏；明确关闭、切换面板或进入全屏时收起。

## 聊天阅读和输入

发件人、时间和消息分开组织，正文 14px、输入 16px；原文气泡下面展示译文。姓名可截断但消息正文允许长词、多语言和换行。

管理菜单收起全员禁言操作；翻译设置默认折叠。消息列表独立滚动，阅读历史时新消息不抢位置，“回到最新消息”恢复跟随。

多行输入：Enter 发送，Shift+Enter 换行，输入法组字时 Enter 不提交。发送中保留状态，失败恢复内容并沿用该次消息标识重试。关闭自动翻译不改变原文。

## 设计证据

`outputs/classroom-responsive-2026-10-24/` 提供 1920×1080、1440×900、1100×800、900×600、740×390、390×844、320×740 的真实组件截图；每种尺寸包含聊天和字幕。另有更多菜单、深色手机示例及可交互的模拟课堂。

检查覆盖：顶部无横向溢出、横屏侧栏不覆盖舞台、竖屏不改变视频尺寸、字幕列表可阅读、草稿保留、历史阅读不跳动、键盘标签切换、网络恢复补消息和重连 RTM。

这些是本地浏览器和替身服务的结果，尚未在真实手机或生产课堂验收。
