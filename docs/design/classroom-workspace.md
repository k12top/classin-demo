## 本次回放实现

- 课次移至视频上方，桌面视频优先分配宽度；1280px 窗口下真实页面视频宽度为 772px。
- 时间线、互动与聊天统一为右侧回看面板，总结使用紧凑的工作台字号、间距与灰绿色状态提示。
- 控制条贴齐视频底部，采用深色渐变与白色控件；进度条在上，播放、音量、时间、字幕、设置和全屏位于下方。鼠标离开后隐藏，键盘聚焦时显示，触屏保留直接可用的操作区域。
- 倍速与画质收入齿轮菜单，显示当前值和选中标记；仅有源画质时显示只读说明。菜单支持 Esc、外部点击关闭与焦点恢复，打开期间保持控制条显示。
- 菜单和字幕设置对话框挂载到视频舞台，支持全屏中的操作。
- 保留媒体倍速同步、片段切换和观看计时逻辑；无最终字幕或仍在读取数据时禁用生成总结，失败后可重试。
- 补齐简体、繁体、英语和越南语的相关文案；学生已发布总结使用只读提示。

本次提交不包含工作区中另行保留的分组页面改动。服务端角色授权没有调整。

## 验证

- 19 项真实 React 组件界面检查：四种语言与宽/窄屏、悬停及键盘访问、底边定位、无重复原生控件、静音同步、倍速菜单、勾选状态、Esc/外部点击、字幕设置与全屏菜单。
- 9 项回放导航、加载状态与总结可见性相关单元测试。
- TypeScript、ESLint、脚本语法与 `git diff --check`。
- 真实教师回放另确认播放后的时间推进、进度条跳转、倍速与字幕设置，以及画质切换后菜单摘要更新。
- 全屏菜单在可见的独立 Electron 测试窗口中检查其所属全屏元素与视口范围；测试结束销毁该窗口，避免等待 macOS 原生全屏退出动画。

组件测试采用只读身份和接口夹具；悬停测试录制元数据不含媒体字节，不用于证明视频解码、真实账号观看计时或云录制端到端验收。上述真实教师页面检查单独进行。
