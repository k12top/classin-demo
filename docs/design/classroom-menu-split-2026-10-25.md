# 课堂功能与常用操作拆分 · 2026-10-25

## Overview

本次为真实课堂极简布局的局部扩展，解决顶部与底部两个“更多课堂操作”重复同一组内容的问题。采用 **顶部找功能，底部做操作**：右上角提供课堂功能与设置，底部保留上课过程中的常用操作。方向依据为 `.impeccable/review/menu-split-20261025/direction.json`。

落地范围是 `classroom-v3.tsx` 的极简布局、`MinimalHeader`、共用菜单组件、局部响应式样式与三种语言文案。根 `DESIGN.md`、`PRODUCT.md` 保留；本次不改写全局视觉系统，也不创建 `.impeccable/design.json`（记录时该侧车不存在）。菜单归属属于当前课堂表面的信息架构，不推广为全站导航规范。

记录状态：**源码实现、最终本地构建、桌面／手机浏览器验证与独立菜单收尾评审已完成。** 验证覆盖本地真实课堂界面的菜单拆分，未部署生产。

## Colors

沿用当前极简课堂的白、灰、靛蓝体系。浅色菜单继续使用白色表面、深灰正文（`#20242b`）、灰色辅助信息（`#657080`）、靛蓝焦点／强调（`#4f46e5`）与浅灰高亮背景（`#f3f4f6`）；边界为淡灰（`#e6e9ee`），危险操作为红色（`#c03545`）。本次没有新增颜色或改变深色主题规则。

## Typography

沿用既有课堂字体，不新增字体或字号层级。菜单项采用既有 14px 文本、17px 线性 SVG 图标和至少 44px 的行高区域。中文简体入口分别为“课堂功能”和“更多常用操作”，繁体为“課堂功能”和“更多常用操作”，英文为“Classroom features”和“More quick actions”。这些名称同时用于可访问名称与提示，图标外观继续沿用省略号。

## Layout

右上菜单从触发器下方展开；底部菜单优先向上展开，均靠右对齐，偏移 8px、碰撞留白 8px。菜单继续使用既有最小宽度 240px、最大宽度 `calc(100vw - 16px)`，并受可用高度限制进行内部滚动。本地浏览器已验证 320px／390px 与桌面 1440px 视口，捕获的菜单均位于视口内，无横向溢出。

共享与字幕在宽屏底部直接可达；视口不大于 760px 时，转入底部“更多常用操作”。此底部菜单的紧凑项显隐被单独约束，避免沿用顶部菜单 1439px 的折叠阈值。画笔继续在底部直接可达。全屏从极简顶部的直接按钮移到底部，新增显隐规则限定于极简 ClassIn 布局，保留旧版布局既有规则。

## Elevation & Depth

沿用既有浮层层级与浅色柔和阴影（`0 8px 28px #1b253314`），不新增装饰层。菜单使用现有 DropdownMenu 的 portal 与碰撞处理；高度不足时内部滚动。两处入口的区别来自位置、可访问名称和内容归属。

## Shapes

菜单继续使用既有 12px 圆角，按钮与键盘焦点沿用现有控件样式。没有新增组件外形规范。

## Components

### 入口与兼容方式

`ClassroomHeaderMenu` 新增 `functions` 与 `operations` 变体，默认仍是 `legacy`。极简顶部显式使用 `functions`，极简底部使用 `operations`。语言子菜单仅出现在顶部功能／旧版菜单，底部操作菜单不再包含语言。

主课堂组件以 `minimalFunctionActions`、`minimalOperationActions` 两组数据分别供给入口，避免两个菜单继续共用同一列表。既有菜单的键盘、外部点击与 Escape 行为由原 DropdownMenu 组件承接。本地验证点击触发器可关闭菜单并保留聊天；Escape 还会通过既有全局处理器关闭当前聊天面板，此行为未修改，不能称为新增或改善的仅菜单关闭行为。

### 功能归属

| 位置 | 内容 | 条件与边界 |
| --- | --- | --- |
| 右上课堂功能 | 设备设置、课件、互动（活动／问题／参与）、助教、举手队列、布局（焦点／宫格／成员）、录制、回放、结束课堂、界面语言 | 沿用角色能力与课堂状态条件；设备设置沿用紧凑屏折叠规则；回放仅结束后；结束课堂保留确认入口 |
| 底部直接操作 | 麦克风、摄像头、举手、共享、画笔、聊天、字幕、全屏 | 沿用原媒体能力与角色条件；共享和字幕在不大于 760px 时折叠到底部菜单 |
| 底部更多常用操作 | 小屏共享／字幕、恢复音视频、离开 | 共享仍受支持能力与忙碌状态限制；恢复与离开沿用现有处理函数及禁用状态 |

顶部功能列表不再放入聊天、字幕、画笔、全屏、恢复音视频或离开。底部菜单不放入课件、互动、布局或语言。结束课堂是教师权限管理功能，保留在顶部；离开是个人退出操作，归入底部。

## Do's and Don'ts

- Do 保持顶部功能与底部操作分别供给数据，菜单名称能表达各自用途。
- Do 将小屏溢出的共享和字幕保留在底部入口，保留直接可达的画笔与全屏。
- Do 保留角色能力、课堂状态、忙碌／禁用状态、危险操作提示与确认流程。
- Don't 将两处“更多”恢复成相同功能列表，或把语言／布局塞回底部操作菜单。
- Don't 把本地截图、TypeScript 或构建通过表述为真实媒体、设备或生产验收。

未规范化或修复的既有漂移：根设计文档章节格式、全局字号与当前局部课堂密度，以及大型 CSS 的累积覆盖关系，均不属于本次菜单拆分范围；本文保留它们，不将检测器建议或既有缺陷固化为新的全局规范。
