## 共享人像行为与调整方式

用户最后修正是本次行为依据：**摄像头关闭时不显示人像；用户开启摄像头后重新叠加。共享功能不得自动打开摄像头或额外申请摄像头。** 摄像头关闭时只有共享内容是正确结果。

在支持的桌面 Chrome / Edge 中打开共享设置，选择「共享＋人像」并授权屏幕来源。共享活动期间再次打开设置，可调整以下项目：

| 控件 | 约束与默认值 |
| --- | --- |
| 形状 | 圆形居中裁切摄像头画面 |
| 大小 | 1080p 合成画布上默认直径 240px，范围 120–240px；界面显示 50–100%，滑块步长 4px |
| 位置 | 左上、右上、左下、右下；默认右下，距相邻画布边缘 40px |
| 边框 | 无、细线、双线；默认白色细线 |
| 边框色 | 白色、靛蓝、深色；无边框时隐藏颜色设置 |

尺寸不只依赖界面的滑块限制。`normalizeScreenShareOptions` 对所有输入路径统一取整、限制范围，并为无效尺寸、角落、边框与颜色设置默认值。边框采用 3px 描边；双线由两个内缩圆环组成。

同一共享模式内更改位置、大小或边框，更新已有合成器选项并立即重绘，不重新申请屏幕采集、不重新建立合成轨道，也不重新设置编码参数。**切换共享模式**涉及输出配置与发布生命周期，不能把同模式外观更新的保证推广到模式切换。

人像模式的输出保留 1920×1080、15fps 画布。每帧先清空并绘制共享内容，再读取当前摄像头；无摄像头、关闭、静音或结束的输入不绘制，之后出现的有效摄像头可重新接入。合成器只拥有输出轨道和渲染资源，不停止 provider 所拥有的输入轨道。

人像模式继续抑制独立摄像头发布，停止共享后走既有摄像头发布恢复流程；恢复仍服从用户当前的摄像头开关状态。课堂权限与共享授权路径保持原有边界。

## 绘图工具与快捷操作

弹层使用五列网格暴露十种工具，屏幕批注隐藏移动工具，保持批注与共享视频对齐。文字工具可调字号 12–60；其他绘制工具可调线宽 1–12。橡皮切换为四档大小按钮；颜色、撤销、重做、删除选中与清空位于同一工具面板。

| 按键 | 工具或操作 | 适用范围 |
| --- | --- | --- |
| V | 选择 | 白板、屏幕批注 |
| H | 移动 | 主白板 |
| P | 铅笔 | 白板、屏幕批注 |
| L | 直线 | 白板、屏幕批注 |
| A | 箭头 | 白板、屏幕批注 |
| R | 矩形 | 白板、屏幕批注 |
| O | 椭圆 | 白板、屏幕批注 |
| T | 文字 | 白板、屏幕批注 |
| E | 橡皮 | 白板、屏幕批注 |
| K | 激光笔 | 白板、屏幕批注 |
| 按住 Shift | 从铅笔临时切换直线 | 白板、屏幕批注 |
| 按住空格 | 临时移动，释放恢复 | 主白板；按钮和链接上不触发 |
| Ctrl/⌘ Z；Ctrl/⌘ Y 或 Shift Z | 撤销；重做 | 主白板保留 SDK 原生历史；屏幕批注由新 hook 显式调用独立视图历史 |
| Delete / Backspace | 删除选中 | 屏幕批注由新 hook 显式处理；主白板保留 SDK 原生键盘路径 |

Shift 临时直线保存原工具。若先松开 Shift、后抬起指针，会等 SDK 收到最终 pointer-up 后再恢复铅笔；失焦和 hook 清理也会恢复临时工具。绘制过程中不会因普通工具字母键打断当前手势。

快捷键跳过输入框、文本域、下拉框、可编辑区域、文本角色、对话框和菜单，也跳过输入法组合、重复按键、已处理事件及不适用的组合键。hook 只在当前绘制表面可用、课堂未结束且拥有白板写权限时启用；屏幕批注控制器还检查连接和写权限。

删除选中是单独动作；清空弹出确认对话框，确认后才调用当前控制器的清空。主白板与屏幕批注的场景和历史继续分离。屏幕批注禁用原生键盘和视图平移，避免批注随主白板移动。

上表记录实现契约与单元证据。用户已人工确认直线、恢复画笔和快捷键正常；该反馈不扩张为每一个表项、输入保护边界及全部平台组合都已逐项验收。
