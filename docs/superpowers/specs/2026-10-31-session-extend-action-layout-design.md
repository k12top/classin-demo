# 课次延长按钮布局修复设计

## 意图

修复课程详情的课次列表中“延长课程”文字被紧凑操作按钮宽度挤成竖排的问题，同时保留明确的鼠标提示和无障碍名称。

## 范围

- 仅影响 `CourseSessionManager` 的 `.rowActions` 操作区。
- 列表中显示紧凑的时钟图标；悬停提示和 `aria-label` 均为当前动作“延长课程”。
- 点击后仍显示延长 15、30、60 分钟的菜单。
- 课堂顶部、课堂菜单等其他 `ClassTimingControls` 使用位置保持完整文字和现有布局。

## 方案

采用组件显式的紧凑模式，而不是依赖全局类名碰撞：`ClassTimingControls` 新增可选 `compact` 属性，课次列表传入该属性。紧凑模式隐藏触发器的可见文字，并设置动作对应的 `title` 与 `aria-label`。这比放宽列表按钮宽度更能保护操作区，也比只写父级 CSS 更清楚地表达组件意图。

### 浅色模式悬停反馈

考虑过两种视觉方案：黑底白图标的强对比反转，以及使用主题浅灰色的次级高亮。选择浅灰高亮，使复制、延长等次级图标操作与现有界面层级一致；“结束课次”继续使用红色危险态。该规则只作用于课次列表的紧凑图标按钮，不改变“查看详情”“进入课堂”或课堂页的控制按钮。

## 验证

- 回归测试固定紧凑模式的提示、无障碍名称和可见文字行为。
- 浅色模式悬停时具有可辨识的浅灰背景；深色模式保持现有主题反馈；结束课次仍为红色。
- 现有课堂使用保持非紧凑模式。
- 对相关文件执行 lint、定向测试，并在本地页面检查课次列表布局和下拉菜单。
