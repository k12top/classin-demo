# 白板默认画笔设计

## 意图

课堂白板首次可操作时默认选中画笔，让教师进入课堂后可以直接书写。

## 范围

- 将课堂白板的初始工具从选择器改为画笔。
- 白板控制器就绪后继续使用现有同步逻辑，把画笔应用到实际 Netless 白板。
- 增加回归测试，覆盖工具栏初始高亮和控制器初始工具。

## 非目标

- 不记忆上一次选择的工具。
- 不改变快捷键、屏幕批注或用户手动切换后的行为。
- 不改变画笔颜色、粗细等默认参数。

## 方案

1. **选定方案：固定首次工具为画笔。** 改动最小，行为确定，符合“白板默认这个工具”的要求。
2. 记忆用户上次工具。未采用，因为会使首次行为受历史状态影响，并扩大存储与恢复逻辑。

## 验收

首次进入可书写白板时，画笔按钮处于选中状态，实际落笔使用画笔；切换其他工具后保持现有行为。
