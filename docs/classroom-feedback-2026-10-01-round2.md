# 2026-10-01 第二轮课堂反馈修正

本轮对应 18 项反馈。以下是代码实现和本地验证记录；尚未发布到生产环境。

| 反馈 | 实现 |
| --- | --- |
| 1. 首页时间难读 | 距离开课改为带单位的天、小时、分钟，按界面语言格式化，并调整手机字号。 |
| 2. 点击空白关闭成员菜单 | 画布外层捕获指针事件，点击画布关闭抽屉；关闭时保持白板尺寸。支持 Escape。 |
| 3. 手机共享画面上方空白 | 收起讲台后使用 32px 高度，移除工作区多余网格行，让共享画面使用剩余区域。 |
| 4. 不录制 | 设置新增“不录制”，阻止手动、自动、恢复录制启动；切换时为正在运行的云录制请求停止并沿用已有收尾流程。 |
| 5. 手机聊天区域 | 抽屉扩大到标题栏与底部按钮之间，标题、关闭按钮、输入框保持可用。 |
| 6. 画笔关闭按钮 | 使用明确的关闭按钮类，固定在右上角，避免依赖最后一个子元素定位。 |
| 7. 白板分页挡住关闭按钮 | 桌面分页控件向内移动；抽屉打开时暂时隐藏分页控件，关闭后恢复。 |
| 8. 更多菜单点空白关闭 | 菜单外点击和 Escape 均可关闭，包括 SDK 画布上的点击。 |
| 9. 静音反复失败 | 独立权限与设置动作不再依赖全课堂 revision；布局操作保留版本保护。仅对可重复的绝对设置动作，在明确的数据库 503 时最多重试两次。操作有忙碌状态和错误反馈。 |
| 10. 语言与外观入口 | 从账户菜单移到管理页顶部，手机端保留入口。 |
| 11. 临时离开位置 | 主讲的临时离开按钮紧邻开始/结束课堂按钮左侧。 |
| 12. 更多按钮灰掉 | 明确显示普通/打开状态，菜单入口保持可点击，与共享和媒体操作状态分离。 |
| 13. 学生白板工具条 | 根据白板可写权限显示工具；权限变化获取新凭证，无需重新入课堂。手机端使用横向触控工具条，避免自动收起。 |
| 14. 手机同意共享无反应 | 不支持 getDisplayMedia 的浏览器明确显示限制并允许关闭请求；支持的浏览器保留用户主动点击开始共享的步骤。 |
| 15. 学生成员页空数据 | 隐藏无成员管理权限的入口，并阻止渲染空成员抽屉。 |
| 16. 管理员静音与恢复 | 成员面板提供全体学生麦克风静音/恢复发言；聊天面板提供管理员全体禁言/取消禁言。恢复发言恢复权限，由学生自行打开麦克风。 |
| 17. 多语言应用失败 | 保存过程显示忙碌、成功或失败；失败保留选择供重试，避免乐观状态更新导致面板重挂载、丢失草稿。保存成功与同传服务运行状态分开显示。 |
| 18. 奖杯无反馈 | 服务端确认奖励后显示奖杯和短暂彩纸动画、获奖者姓名，并更新累计数量。尊重减少动态效果偏好；不自动重试奖励，避免重复发放。 |

为减少数据库压力，状态轮询不再重复写成员在线状态，在线维护和同传恢复使用心跳；普通状态轮询为 5 秒，录制过渡状态为 2 秒，实时信令继续触发刷新。

## 验证

- 全仓库 `npm test`：108 项通过。
- TypeScript、修改范围 ESLint、生产构建、差异空白检查通过。
- 本地 Chrome 使用实际 React/CSS 和模拟 API、声网、Netless，确认桌面与 390×844 手机视口的菜单关闭、抽屉布局、静音重试/恢复、奖杯反馈、多语言失败恢复、不录制选项、授权后学生工具条、共享期间更多入口、手机共享限制提示、管理页语言/外观及倒计时。
- 模拟数据库 503 与同传保存 500 验证恢复流程；这不构成生产数据库或真实同传服务验收。

`recordingStartMode` 已是数据库文本字段，本轮新增 `disabled` 值无需新增数据库迁移。已有迁移是否在生产执行，应以生产数据库迁移记录或构建日志确认。

真实手机浏览器权限与共享能力、声网/Netless 跨端同步、真实多语言同传、云录制停止与文件收尾，需要发布后通过实际账号和设备验收。本轮未部署，也未运行生产数据库迁移。
