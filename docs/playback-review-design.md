## 页面任务

教师和学生在同一页面完成三件事：观看当前课次录像、定位某一句发言、阅读该课次总结。视频是主内容；时间线是视频的目录；总结提供快速回顾。

## 布局

- **单课次**：直接显示课次标题、视频和右侧内容面板，不显示课次列表、选择条或“第 1 课”孤立按钮。
- **多课次**：左侧显示课次回放列表，包含课次名称、日期、时长和可用状态。切换课次时，视频、时间线、总结一起切换；屏幕较窄时改为一个课次下拉框。
- **右侧内容面板**：仅放“发言时间线”，与视频同一行，方便边看边定位。移动端将时间线排在视频下方。
- **课后总结**：放在视频和时间线下方，横跨两个内容列。概述、要点和教师审核操作使用完整阅读宽度；发言人统计在宽屏作为侧栏、窄屏移到正文下方。视频标题处提供页内跳转入口。
- **视频画面**：默认不叠加字幕；点击 CC 可显示或隐藏双语字幕，旁边的设置可切换只看原文、只看译文或双语，并调整语言、背景、字号和位置。发言时间线仍保留双语内容。教师画中画使用圆形裁切、完整圆边和轻阴影，保持课堂中右下角的视觉效果；真实回放应尊重录制时保存的位置与形状，避免出现默认右上角矩形画面。
- **多段录像**：视频下方显示片段按钮；这是同一课次内的录像分段，和左侧课次列表有不同层级。

## 时间线到视频

1. 每句最终字幕显示该课次内的时间、发言人、原文和译文。整行可点击，键盘也可激活。
2. 点击后选择覆盖该句时间的录像片段，等待媒体可定位，再设置 `video.currentTime`。播放器进度、当前字幕高亮和片段按钮同步更新。播放中可以开启“跟随播放”自动高亮，不强迫页面滚动。
3. 字幕的 `occurredAt` 是墙上时钟时间，不能直接作为视频秒数。定位应基于**实际媒体起点**与录制分段的起止时间计算偏移，并在片段切换时处理加载/缓冲。若现有录制元数据不足以可靠对齐，先显示“无法精确定位”，不能跳到猜测位置。
4. 课程结束后仍未保存最终字幕的旧课次，时间线展示空状态；视频和总结独立可用。

## 教师与学生

- 学生只看已发布的总结；教师可查看草稿并进入审核编辑。审核动作放在独立总结区，不盖住时间线。
- 总结的重点可关联时间线句子时，点击重点也能定位视频；没有可靠关联时只显示文字。
- 切换课次时，时间线和总结都切换到对应课次，并重置播放位置与高亮；直链 `?sessionId=` 仍直接打开指定课次。

## 视觉方向

沿用课堂现有紫色作为定位与选中状态；播放器使用深色控制带，正文用浅色阅读面板。时间线的小圆点和刻度是唯一强调性的图形语言，表示“这一句对应录像中的一个时刻”。中文正文优先系统黑体，时间码使用等宽字体。

## 正式实现需补的数据与验收

- 为每个可播放片段确认真实媒体起点、结束时间、媒体时长，处理录制开始延迟和中断。当前 `startedAt` / `stoppedAt` 字段不足以证明与媒体时间轴精确对齐。
- 将视频播放器的 `seek`、`timeupdate`、`loadedmetadata` 与时间线置于同一状态控制层；MP4 与 HLS 共享跳转契约。
- 确认录像是否已把摄像头和字幕烘焙进画面：若已烘焙，播放器无法通过 CSS 去除，只能调整录制合成或选择无字幕的源；若是回放页叠加层，则直接关闭该叠加层。圆形画中画的位置与形状也应在录制链路中保留。
- 验收单课次无列表、多课次切换、同一课次多片段、时间线定位误差、无字幕、无录像、总结草稿权限，以及移动端操作。
