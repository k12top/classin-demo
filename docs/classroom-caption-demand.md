# 课堂字幕按需翻译

课堂保留原文转写，译文按参与者的选择开启。首次进入默认仅原文；保存过的显示方式和语言继续沿用。老师和学生的个人语言选择使用同一条订阅接口，老师仍可设置课堂主要语言及整体开关。

字幕面板默认展示发言记录与当前显示方式。右上角设置按钮及摘要右侧箭头向下展开设置卡片；修改先保留为草稿，应用成功后自动收起，直接收起则丢弃未应用修改。失败时保留卡片和草稿供重试。翻译通道和舞台字幕说明收进标题旁的感叹号提示，悬停、键盘聚焦或触摸点击时显示；面板不再展示正在使用的翻译语言列表。

字幕侧栏从顶部工具栏下方延伸到可用屏幕底部，手机保留底部操作栏与安全区域。发言列表填满剩余高度并独立滚动；设置区按内容高度展开，收起后不占高度。高度不足的手机横屏在编辑时暂时隐藏记录列表和摘要，收起后恢复。设置底部操作按钮保持可见，错误和重试留在编辑区域。

三个下拉框使用 Radix Select，将菜单挂载到课堂根容器，避开侧栏、滚动区和展开动画的裁剪。菜单保留课堂主题、键盘选择和触摸操作，按视口可用高度滚动并自动避让边界；Escape 先关闭菜单，再次按下才收起设置。

`POST /api/sessions/{sessionId}/classroom/caption-preference` 接收 `clientId`、`language` 和可选 `shareAccess`。`language: null` 表示不需要翻译；选择与课堂原文相同的语言也不创建翻译通道。身份从登录会话解析，只允许修改本人已加入且未退出的连接。

订阅保存在 `ClassroomConnection.captionLanguage`，按浏览器标签页区分。课堂输出是有效连接订阅的去重集合；同一语种由多人共用。切换语言、仅原文、关闭字幕或离开课堂会释放本人需求，连接超过 120 秒未续约也会在字幕恢复检查中被移除。前端每 20 秒重申当前选择，以恢复中断的请求；相同订阅不重复写连接记录，也不重复更新翻译任务。录制页面不订阅翻译。

语言列表来自 `translation-capabilities.ts` 中的服务能力表，独立于 23 种界面语言和当前已开启的通道。声网旧版 join/update 接口最多同时开启 10 个目标语种，Wordly 桥接的应用上限为 20。所有支持的语言都可在列表中选择；超过当前并发容量时，接口返回 `caption_language_limit`，事务回滚并保留原选择。Wordly 不支持的语种不会出现在其列表里。

服务端锁定课堂运行状态后汇总需求，避免并发用户覆盖彼此的选择。`transcriptionConfigKey` 记录已应用的服务配置，`transcriptionSyncLeaseUntil` 在多个实例间串行化服务更新。更新期间发生的新选择会再次汇总；中断的同步由个人订阅重试、老师心跳及现有定时恢复流程继续处理。无译文需求时，声网关闭 `translateConfig`，Wordly 不再执行字幕翻译调用，原文转写继续用于课堂字幕及回放。

发布时须应用 `20261013090000_caption_translation_demand` 迁移并重新生成 Prisma Client。迁移为连接增加订阅字段、为运行状态增加同步字段，清除未结束课堂的旧预设输出语种；后续由实际需求重新开启。

验证：`npm test`；`tests/integration/classroom-caption-demand.cjs` 在已应用 schema 的隔离、回环 PostgreSQL 数据库 `classroom_captions_*` 中运行，覆盖学生选择、共享通道、同时选择、服务更新期间切换、多标签页、退出、过期、容量回滚、越权、旧客户端、原文及结束状态。数据库是真实 PostgreSQL 查询，外部转写与翻译接口使用模拟边界；另以真实 React 面板和订阅 Hook 验证桌面、390px 手机、语言过滤、失败重试与选择持久化。
