# 桌面客户端（Electron）

客户端默认打开已接入真实后端的桌面工作台：登录后查看当前账号的课程、课节、日历、学生和分组，新建课程并可同时安排首节课。从课节进入项目现有生产课堂，继续使用其 Agora 音视频、白板、课堂聊天、互动和录制能力。

桌面首页直接加载所配置站点的共享工作区，与网页使用相同的首页、日历、学生、分组、To Do、云盘和聊天界面。独立设计原型保留在 `design/classin-v5/`，其中的示例数据不代表真实业务数据。桌面端通过 Electron 外壳提供独立课堂窗口、系统窗口控件和媒体能力。

## 登录与窗口

工作区沿用站点的 Casdoor 登录和现有第三方账号配置。课程、成员、教学人员、课件及回放使用共享站点的界面和服务。macOS 使用原生红黄绿窗口按钮，Windows 使用原生窗口控制按钮，两者与工作区顶部区域合并。

页面连接失败、文档加载超过 30 秒或渲染进程退出时，显示随应用打包的连接恢复页，可重新连接或返回工作台；已有课堂窗口仍保持独立。重试目标由主进程保存，本地页面不能指定任意地址；Casdoor 或登录回调失败时重新发起登录，不重放旧授权码。该页面使用与工作区一致的紧凑字号，支持简中、繁中、英文和越南语。

| 快捷键 | 入口 |
| --- | --- |
| `⌘/Ctrl + 1` | 桌面工作台 |
| `⌘/Ctrl + 2` | 人员工作台 |
| `⌘/Ctrl + 3` | 当前课堂 |

首页、人员工作台和远程课堂使用独立窗口；人员工作台是非模态窗口。客户端只允许一个活动课堂，从首页、远程页面的普通跳转或 SPA 跳转进入另一课节时，均要求先退出当前课堂。

人员工作台复用既有实现：花名册搜索、举手/台上/暂离筛选、上下台、发言和板书授权、奖励、全体静音，以及学生分组的搜索、多选、添加和确认移出。分组每页 12 人、每批最多 100 人；可见花名册每 3 秒尝试同步，同一时间只执行一个读取。教师、助教及学生权限由服务端校验，学生花名册只读。

## 数据与安全边界

- `src/main.cjs` 管理窗口、导航、媒体权限及 `classroom-client://` 本地资源白名单；`src/api-client.cjs` 在主进程通过 Electron `session.fetch` 使用共享的 HttpOnly 登录会话。
- 本地人员和屏幕选择窗口只使用限定操作桥，启用沙箱与上下文隔离，禁用 Node 集成和任意跳转。首页是配置站点的网页，使用站点自身的认证与网络请求；不能将本地页面的 CSP 约束等同于网页首页的安全策略。
- 写请求携带配置站点的 `Origin`，继续经过服务端鉴权及同源/CSRF 校验。并行读取遇到 401 共用一次登录续期；续期或网络暂时失败保留已加载内容，确认未登录后清空账号数据。写操作不会因网络失败自动重放。
- 新建课程支持可选首课，将排课时区内的时间转换为 UTC 并携带 IANA 时区；拒绝无效顺序和夏令时不存在时间，重复时间引导使用完整排课页明确选择。同一创建对话框的重试复用一个幂等键，结果未确认时应先刷新课程列表。
- 进入课节前调用现有访问核验接口，校验返回的课堂来源、路径和课节。摄像头、麦克风与屏幕共享权限限定于配置站点的课堂主框架；通过应用内带预览的来源选择器，由用户明确选择要共享的屏幕或窗口。

## 开发与构建

```bash
cd clients/desktop
npm ci
CLASSROOM_WEB_URL=http://127.0.0.1:3000 npm run dev
```

本地站点须另外启动，并具备可用的后端与统一登录配置。开发默认连接 `http://localhost:3000`，打包默认连接 [生产站点](https://live.xiangyuwenshu.cn)。`CLASSROOM_WEB_URL` 可指定其他 HTTPS 部署；HTTP 仅接受本机回环地址。

macOS 打包会使用本机 Apple 开发工具链编译 Apple Silicon 与 Intel 通用的远程输入辅助程序，并将其放入应用资源目录参与应用签名。开发时可运行 `npm run native:build` 生成该程序。Windows x64 已接入独立的远程输入接收程序，构建需要 MinGW-w64 的 `g++` 和 `windres`；macOS/Linux 可使用 `x86_64-w64-mingw32-g++` 交叉编译，也可通过 `CLASSROOM_WINDOWS_CXX` / `CLASSROOM_WINDOWS_WINDRES` 指定配套工具链。Windows ARM64 构建目前会明确拒绝。

课堂沿用远控请求、学生同意、绑定共享连接的签名输入及短时授权：学生须使用包含接收程序的桌面客户端共享整个屏幕；macOS 还需辅助功能权限。共享或授权失效、屏幕配置变化及停止控制时释放输入。Windows 接收程序使用当前用户权限，不请求提权或 UIAccess；不能控制权限更高的程序或系统安全桌面。Windows 客户端仅在打包包含接收程序时声明支持接收远控。协议、模拟输入及服务端集成测试不代替真实师生设备验收，目前鼠标、键盘和多屏操作仍需两台设备实测。

应用图标复用项目的 `public/site-logo.svg`，图标资源位于 `resources/app-icon.png`、`resources/app-icon.icns` 和 `resources/app-icon.ico`，分别用于运行时、macOS 应用和 Windows 应用及安装程序；开发版 Dock 也使用同一 Logo。更新站点标识后，可先安装仓库根目录依赖，再在客户端目录运行 `npm run icon:generate` 重新生成图标。

```bash
# 固定操作、安全契约、时间换算及窗口路由测试
npm test

# 当前平台的应用目录，默认输出 dist/
npm run package

# macOS Apple Silicon，复现本轮输出目录
npm run package -- --mac --arm64 --config.directories.output=dist-live-verified

# Windows x64 远控辅助程序及应用目录（需要 MinGW-w64）
npm run native:build:windows
npm run package -- --win --x64 --config.directories.output=dist-windows-verified

# 按 package.json 的平台配置生成分发包
npm run dist
```

## 验证与证据

桌面课程列表支持 SQLite 弱网缓存：在线读取后使用系统安全存储加密，按服务地址和登录会话隔离；网络临时不可用时，在当前已登录会话内最多显示 24 小时内的缓存。系统加密不可用时不会持久化课程内容。登录或课程访问被拒绝时不再展示该缓存。缓存不替代服务端数据，也不支持离线修改；目前聊天、云盘等数据未缓存，应用冷启动仍需联网加载页面和验证登录。

2026-11-08 的接入验证覆盖了原生教师登录、课程读取、课堂音视频、白板载入和消息发送；该次学生接收及多端同步未验收。2026-11-11 本地验证了真实师生账号入课、学生共享和远控授权状态，独立声网测试频道验证了合成音视频及共享画面传输，独立白板客户端验证了画笔同步。远控鼠标和键盘仍需两台设备验收；真实师生弱网、回放完整播放和 Windows 学生端远控接收也尚未完成验收。

可提交的界面截图均使用虚构人员和接口夹具；夹具不连接真实媒体，也不能证明原生登录或 RTC 链路。运行及证据范围见 [接入验证记录](verification/live-integration/README.md)。真实账号和课堂截图仅保留在本机 `outputs/desktop-live-integration-2026-11-08/`，不随仓库提交。
