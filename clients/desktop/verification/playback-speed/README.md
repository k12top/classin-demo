# 回放倍速控件

2026-11-12，`feature/classin-unified-workspace`。对照 `design/classin-v5/learning.js` 回放控件和已批准截图补齐显式倍速入口，网页与 Electron 使用同一组件。

- 默认提供设计稿的 0.75×、1×、1.25×、1.5×、2×。名称支持简中、繁中、英文和越南语，数字按界面语言格式化。
- 状态放在当前回放页面，手动切片、自然播放结束后的下一片段、切换课节及源重载保持所选速度。刷新或离开该页面后恢复默认，不增加本地持久化。
- 浏览器原生媒体菜单修改受支持的速度时同步下拉框；额外受支持的原生速度会显示为当前选项。速度范围沿用服务端观看进度策略。
- 默认速度与实际速度可能触发重复 `ratechange`；计时只在实际速度变化时结束旧会话并建立新会话，未改变服务端计时规则。
- 320 像素下，字幕控件与长状态提示不再被压成逐词多行；提示保留完整标题和辅助技术文本。

## 验证

```bash
CLASSROOM_PLAYBACK_TEST_MEDIA=/absolute/path/to/synthetic.mp4 \
  clients/desktop/node_modules/.bin/electron tests/integration/playback-stability.cjs --speed-only
```

隔离 Electron 运行真实回放页面、速度组件和合成 H.264 MP4，实际媒体时钟以 1.5× 前进；验证原生菜单同步、源重载、手动切换片段、真实结束事件触发下一片段继续播放、切课保留，以及一次速度修改只启动一次新计时、相同事件不增加计时会话。登录、课节列表和计时回执为夹具；不能代替真实学生计时闭环。

简中 1366、繁中 1024、英文 390、越南语 320 的四组控件边界检查通过，查看桌面与窄屏截图后修复长提示排布，并已确认。截图和检查记录仅存本机 `outputs/playback-stability/speed-*.png` / `speed-result.json`。47 项回放相关测试、TypeScript、定向 ESLint 和 diff 检查通过；组件已核对 React hooks、事件清理、语义和共用状态。

本轮尝试使用临时真实班级和合成视频复测时，OSS 上传返回 60 秒超时，尚未进入真实账号倍速播放验证。随后核对本地临时回放班级为 0，专用 OSS 前缀 `codex-verification/playback/` 列表未截断且为空，没有残留本轮测试数据。此前真实教师 OSS 正常播放的证据仍只覆盖先前版本，不计为本轮倍速验收。

回放壳和学习时长提示的越南语仍有英文回退，真实学生、实际弱网、原生客户端及 Windows 验收继续进行。整体目标未完成。
