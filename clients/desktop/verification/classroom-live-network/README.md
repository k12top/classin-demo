# 真实课堂互动：延迟、回执丢失与答案范围

2026-11-12，`feature/classin-unified-workspace`。使用教师 test1 的内置浏览器会话、学生 rainy/test 的独立 Chrome 会话，进入正常课堂页面、连接实际课堂服务并由教师开始/结束测试课。没有提取、注入或替换登录身份。

## 网络边界

`tests/fixtures/classroom-live-network.cjs` 在专用本地 PostgreSQL 创建可清理的班级和课节。仅该课的互动 HTTP 经 3185 loopback 代理增加 180ms 交付延迟，并可从代理终端输入以下单次规则：

```json
{"action":"create","delayMs":8000}
{"action":"answer","drop":true}
{"action":"answer","delayMs":8000}
```

代理不替换响应体、身份或权限判断，业务由现有 Next.js 服务和真实数据库处理。声网通道保持原连接；本次不是全系统限速、丢包或音视频弱网验收。课堂自动录制关闭，未开启麦克风、摄像头、字幕或屏幕采集。

## 实测

| 操作 | 页面及数据库证据 |
| --- | --- |
| 多选题手动调整选项 | 删除/添加后保留 3 个选项，学生收到多选复选框；数据库 type=multiple、options=3 |
| 单选题手动调整选项 | 删除至 2 个选项，学生收到单选单选框；数据库 type=single、options=2 |
| 判断题 | 两个固定选项，数据库 type=boolean；未误变为其他题型 |
| 发布回执延迟 8 秒 | 教师在点击后约 278ms 已显示发送中的题目；学生在约 4642ms 观察到题目，早于教师回执交付 |
| 学生答题回执丢失 | 首次写入后连接被丢弃，客户端重试成功；多选题仅一条作答、answerVersion=1、10 分，没有重复提交版本 |
| 答题回执延迟 8 秒 | 判断题已在服务端提交，教师约 545ms 内观察到 1/1 作答和选项统计，早于学生回执交付 |
| 仅已作答 | 已作答多选题显示正确选项与 10/10；未作答单选题仍无参考答案、评分或已揭示选项，数据库 scope=answered、responses=0 |
| 全体学生 | 未作答单选题改为 scope=all、published，仍为 0 次作答，但学生可查看正确选项，输入关闭，不伪造学生作答或成绩 |
| 错误反馈 | 判断题故意选错，原选项行标红、0/10，正确选项同区标识；没有另起重复答案区 |
| 教师统计条和头像 | 通过 Enter 展开统计条的学生浮层，看到 rainy 和错误标记，头像右上角有错误气泡；本轮未用原生鼠标执行 hover |
| 总体与课后看板 | 课堂与课后均保留 3 道题、2 次作答、66.7% 参与率、50% 正确率；教师可查看全班信息，学生回看保留本人的 0/10 和错误标红 |

以上毫秒数是工具观察到页面状态的上界，不是精确首帧性能指标。发布、作答的 8 秒延迟由代理记录确认；答题延迟场景的答案下发发生于回执返回之后，不计为“迟到回执覆盖评分”的真实验证。

## 发现并修复的读取恢复问题

真实下发全体答案时，学生曾因一次读取失败保留旧状态较长时间。检查发现：正常实时通道的 60 秒校准间隔也成了失败后的起始重试间隔；版本变化通知在退避期间不能越过该间隔。

- 互动列表和题目详情现在显式配置 8 秒失败退避上限，按 2、4、8 秒重试。成功后恢复原正常间隔，通知仍合并，任务仍不重叠，离线暂停和卸载取消保留。
- 先增加两个调度测试复现失败，再修复。`activity-release-recovery-ui.cjs` 使用实际 feed/detail/学生浮层，原生 HTTP 同时断开列表和详情，保持故障直至应用确认失败，再恢复连接；无需 focus、手动重试或重复写入，约 2041ms 自动显示全体下发的答案并禁用旧作答控件。
- 该自动恢复时间来自隔离 HTTP/身份/数据与 realtime-ready 标志的组件测试；不把它作为真实账号精确恢复时延。真实账号范围、发布、答题和反馈另由上述页面与数据库实测。

## 检查和清理

当前项目 1049 项测试、桌面 107 项测试、TypeScript 和定向 ESLint 通过；教师写入回执恢复回归、互动看板的 16 种语言/角色/宽度及读失败/撤权恢复回归通过。最终生产构建在独立临时目录通过编译、类型检查、28 页生成和追踪，目录已清理；占位数据库地址不代表生产连接验收，未部署。

开发过程中热更新曾报告 effect 依赖长度改变；浏览器翻译扩展注入 `data-immersive-translate-page-theme` 也产生了 hydration 警告，未通过隐藏警告修改产品。测试截图保留开发工具的提示，不宣称控制台无错误。

教师通过实际退出对话框结束课堂；数据库确认课节 finished、runtime ended、字幕 stopped、录制 disabled，录像记录为 0。两端返回原有课程并保留各自登录，恢复学生简中与教师英文；代理已停止，临时班级、互动、作答与关联本地记录清理完成。原有课程、名单和作答未变动。

本机证据在 `outputs/classroom-live-network/`：代理事件、`timing.json`、数据库检查点、自动恢复结果、清理结果，以及实时/课后看板、答案范围、错误标红和学生名单截图。它们不随仓库提交。

仍需原生 Electron 硬件和断线恢复、完整课堂录制/字幕对齐、音视频全链路弱网、双设备远控和 Windows 实机验收。整个设计稿实现目标保持 active。
