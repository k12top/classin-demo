# 互动看板国际化与恢复验证

2026-11-12，分支 `feature/classin-unified-workspace`。网页与 Electron 继续复用同一组课堂组件；本轮未增加客户端专用业务页面。

## 本轮修改

- 课堂看板、互动历史、图表说明和录像跳转提示补齐繁体中文与越南语。
- 共享互动控件补齐繁中和越南语，包括题型、作答、正确/错误、保存冲突、发布、批阅，以及“仅已作答学生”和“全体学生”两种答案范围。未翻译的其他界面语言使用英文回退，避免出现简体中文。
- 越南语基础互动字典补齐 108 个文案，包含错误恢复、题型/状态、管理与作答工具；参数占位符与英文字典一致。

## 已验证与边界

从仓库根目录执行：

```bash
clients/desktop/node_modules/.bin/electron tests/integration/activity-dashboard-recovery-ui.cjs
```

隔离 Electron 运行真实 `ActivityDashboard`、图表、作答详情与 `I18nProvider`，只替换 HTTP 数据、身份及显示时区。四语言 × 教师/学生 × 1366/320 像素的 16 组布局通过，检查横向边界、标题、控件与提示。学生未下发结果不显示正确选项标记、评分或教师作答选择器。截图位于本机 `outputs/activity-dashboard-recovery/`；这些数据是夹具，不证明服务端授权或真实弱网已经验收。

本机 HTTP 服务真实中断响应连接，验证已有内容读取失败后结束忙碌、保留此前授权内容、获得焦点后重新读取；403 清除内容。首次读取的连接中断也结束加载、显示重试，并在恢复焦点后加载成功。没有改变生产超时或重试策略，不能据此认定此前真实学生窗口卡住的根因已经修复。

35 项互动/统计/相关语言测试、TypeScript、定向 ESLint 与 diff 检查通过；另核对 108 个越南语基础文案的字段和占位符，以及语言变体与英文回退。

真实本地教师 `test1` 在越南语页面读取实际看板，选择 rainy 的作答，确认“Đúng”及 10/10；截图 `outputs/activity-dashboard-recovery/real-teacher-vi.png` 仅保留本机，验证后已恢复英语界面。课节无可播放录像，且回放壳部分导航仍回退英文，本轮不据此声称整个回放国际化完成。

真实学生 Electron 当前受 Mac 锁屏影响，尚未继续验证。待解锁后仍需检查原窗口、实际断线恢复和学生权限；双设备远控、Windows 实机与完整录像仍在整体验收范围内。
