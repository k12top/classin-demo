日期：2026-11-08。范围为 Electron 桌面客户端：v5 工作台接入现有后端，课堂复用生产实现。本目录截图使用虚构人员和接口夹具；真实账号、课程及设备画面保留在本机 `outputs/desktop-live-integration-2026-11-08/`，不提交或复制到本目录。

## 可复现检查

```bash
cd clients/desktop
npm ci
npm test

# 浏览器界面夹具：http://127.0.0.1:3184/
node test/live-fixture-server.cjs
```

夹具直接使用当前 `src/home/` 的界面、v5 样式和固定操作描述；底部黄色测试条可以模拟 503、恢复连接和登录过期。它的登录、入课、人员窗口及导航桥均为测试替身，不启动 Electron 会话、Casdoor 或音视频。重启夹具服务恢复初始数据。

另有 `test/fixture-server.cjs`（3180）用于既有人员工作台的局部验收，不等同于本轮首页夹具。真实原生入口的启动、打包命令见 [桌面 README](../../README.md)。

## 契约与路由测试

本轮 `npm test` 共 19 项通过，覆盖既有人员操作契约与时间换算，以及真实接入新增的固定请求描述、参数和来源校验、共享登录续期、网络超时、空数据、课程创建幂等键和单课堂窗口路由。路由测试包括首页入课、远程完整导航与 SPA 导航之间的冲突处理，以及人员窗口重新打开时的上下文。

这些是 Node 测试与窗口替身测试，不是原生平台视觉检测或学生端 RTC 测试。本轮未运行原生平台机械设计检测器。

## macOS 原生与真实后端验收

使用 macOS Apple Silicon 运行真实桌面入口，完成以下操作；验收记录来自本轮原生操作与后端读取，私有截图未纳入仓库。

- 通过现有 Casdoor 统一登录完成教师登录；路由修复后重新构建的客户端重启可恢复会话，最终首页读取到 47 个真实课程（含本轮新建验收课程）。
- 创建独立、零学生的验收课程与首课，从工作台进入真实课堂，课堂连接状态显示 `Good`。
- 在教师设备开启摄像头并观察自览；开启麦克风，观察到电平与字幕；白板已载入；在真实课堂发送文字消息。
- 启动屏幕共享，但当时仅观察到教师端自身画面，尚未证明学生端收到正确屏幕内容。
- 停止麦克风、摄像头、共享和录制后结束课堂；后端课节状态为 `finished`，关联一条录制。最终原生课程页展示 `1 / 1 课节已结束` 及“回放与互动”入口。
- 已打开的花名册窗口通过首页“管理学生与分组”入口重新进入时，实际切换到分组页。
- 路由修复后重新构建 `dist-live-verified/mac-arm64/翔宇文淑课堂.app`；当前无 Developer ID 签名及公证。

白板、互动、课堂聊天与录制继续使用生产课堂能力；复用实现不等于本轮逐项完成多端验收。学生接收端、白板绘制及多端同步、真实弱网、回放完整播放、Windows 和签名分发均仍需验收。

## 设计基线与扩展边界

运行首页引用 `design/classin-v5/style.css`，保持批准的 13px 正文、浅色侧栏、黑色主操作与课程封面；课程详情和窄窗口表单沿用同一系统。设计依据见 [v5 说明](../../design/classin-v5/README.md)。根 `PRODUCT.md`／`DESIGN.md` 与桌面 v5 的字号和主操作色存在范围差异，本轮保留两者，未改写全局设计规范或令牌。

To Do、云盘、站外私聊、自动翻译及其他 v5 示例仍在独立设计预览中。真实首页没有将这些内存示例包装成后端能力；完整管理与回放入口转到现有站点。
