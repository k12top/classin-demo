# 桌面端视觉与交互方向 v2

## 任务与使用场景

教师在日常明亮环境下长时间备课、上课和管理学生。界面应降低持续观看的视觉负担，让用户首先看见当前任务和下一步操作。保留 ClassIn 的教学组织方式，替换早期设计中厚重的窗口装饰与高饱和强调。

## 视觉变量

| 变量 | 值 | 用途 |
| --- | --- | --- |
| Canvas | #FCFCFD | 主画布 |
| Surface | #F3F4F6 | 侧栏、辅助区域 |
| Ink | #24272E | 正文、主要按钮 |
| Secondary | #606773 | 次要信息 |
| Accent | #526DDD | 焦点、选中、链接 |
| Line | #E1E4EA | 必要分隔 |
| Danger | #B83B48 | 错误、破坏性操作 |

系统中文字体，正文 14–16px，页面标题 24–28px，课程标题 18–20px。避免把标题当装饰性大字。主要操作使用深色底与白字，辅助操作使用文字或轻描边。普通文字对比度至少 4.5:1。8px 间距基准，常规行距 1.5；按钮圆角 8px。分隔与留白建立层级，不依靠卡片套卡片。

## 布局

主要逻辑画布为 1440×900，支持到 1024px。全局导航约 184px，文字配图标，浅色背景。首页不同时常驻班级列和日历列；默认只突出下一节课。课堂成员侧栏约 280–320px，可收起，收起后主舞台扩展。成员、聊天与互动共用一个侧栏。学生分组在内容区切换，隐藏重复的分组列。

## 功能组织

- 首页：今日课程与我的班级为清晰的不同视图；备课、回放和互动记录随当前课节展示。
- 课堂：教学工具与设备控制分区。结束课堂需要确认，使用明确危险文字，不用醒目的大红按钮抢占课堂注意力。
- 成员：点选成员后展开该成员操作；举手、离线与权限状态必须有图标或文字，不能只靠颜色。
- 学生：批量移出在选中后显示；创建、改名等分组操作从“管理分组”进入。未知图标不能代替功能名称。
- 全局：使用同一套线性图标，尺寸与笔画统一。生成图中的书本标记不视为新品牌标识；现有品牌资产优先。

## 状态与边界

显示加载、无课程、无学生、搜索无结果、权限不足、断网和同步未确认状态，保留当前选择与输入。收起界面元素不移除既有功能。依赖接口或权限的入口只在可用时显示；尚未实现的能力不能伪装成可用。

保持老师本地 camera 与 display track 分开；仅共享时仍可看到自己。答案下发继续区分仅已作答和全体学生；错误使用红色结果标记，正确使用可辨别的勾选标记。侧栏数据同步不能因慢请求重叠而长期不展示结果。

## 设计评审结论

三个设计稿已按核心任务与视觉一致性检查。当前交付为内置 image_gen 生成的修订概念稿，不包含真实运行验证。接下来实现应以用户明确的简约方向为依据，代码验收须另行检查可访问性、1024px 窗口、键盘操作、权限和弱网状态。
