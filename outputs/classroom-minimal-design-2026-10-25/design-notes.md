# 极简课堂设计稿说明

本目录是待确认的设计提案，继承现有 `PRODUCT.md` / `DESIGN.md` 的明亮、中性底色与靛蓝交互强调；没有形成新的全局设计系统，整套新视觉尚未应用到课堂；现有课堂的局部滚动修复另见后文。

**可见层级。** 主画面、成员姓名与课堂内容优先；常驻控制采用可识别 SVG 图标。麦克风/摄像头的开关状态、未读提示、录制提示与网络异常保留直接可见的状态反馈。人物姓名不随操作按钮一起隐藏；连接异常显示说明与重试入口，不能要求用户悬停后才发现。

| 收起的常驻文字或详情 | 查阅与操作入口 |
| --- | --- |
| 麦克风、摄像头、共享、举手、聊天、同传等按钮名称 | 图标悬停或键盘聚焦显示短名称与必要状态；点击执行或打开对应面板 |
| 课程完整名称、老师、计时、连接详情、延时、录制 | 课程弹层；也可从「更多 → 课程」进入 |
| 同传译文语言、原文/双语/译文、画面字幕、字幕外观 | 同传侧栏的设置图标；「更多 → 设置 → 同传」也可进入 |
| 聊天自动翻译与译文语言 | 聊天侧栏的翻译图标弹层 |
| 成员管理与消息操作说明 | 成员画面悬停/聚焦后的操作、消息省略号菜单；触屏可点按或长按展开 |
| 音视频设备、界面语言、外观、布局、互动等次级功能 | 「更多」及其弹层 |
| AI 助教 | 「更多 → 助教」，不占用常驻主工具栏 |

**输入方式。** 桌面图标悬停约 350ms 出现说明，键盘聚焦立即显示，焦点样式保留；点击打开可操作弹层。Esc 依次关闭确认框、弹层、说明或侧栏。触屏点按图标执行/展开，长按约 500ms 查看图标说明；长按消息打开操作菜单，点按人物画面显示操作。长按说明后不同时触发原按钮。所有常驻图标提供可访问名称，辅助文字不能只依赖鼠标。

**响应式。** 聊天和同传共用一个容器，通过标签切换，聊天草稿在切换后保留。桌面侧栏占用独立宽度（默认 1440px 示例为 328px，紧凑桌面为 304px），主画面随可用空间调整。手机竖屏使用底部浮层，保持主画面的原有几何尺寸，浮层会覆盖下部内容，可收起；并非所有内容始终无遮挡。手机横屏改用右侧默认 280px 独立区域，避免底部浮层挤占有限高度。320px 小屏、超宽屏及手机深色状态均有对应截图。

**左右分隔线（本次补充）。** 桌面与手机横屏中，鼠标靠近主画面和右侧面板的交界时，中段出现细拖拽线，光标变为左右调整；常态隐藏，键盘聚焦或拖动时保持可见。触屏横屏保留淡色把手，竖屏底部面板不显示左右调宽入口。

- 桌面最小 280px，横屏最小 240px；最大为 `min(480px, 可用宽度 × 40%)`，左侧至少保留 60%。到达边界停止扩张，不继续挤压主画面。
- 聊天／同传共用用户宽度，关闭再开和刷新后保留；缩小窗口临时按新上限收紧，放大后恢复用户原选择。
- 双击分隔线恢复当前屏幕的默认宽度；聚焦后左右方向键调节，Home／End 到最小／最大宽度。
- 本地浏览器已使用实际鼠标事件检查拖拽、上下限、松手结束、宽度保留、窗口自适应、键盘、双击及手机竖屏回退，记录见 `resize-checks.json`。仅交互设计稿验证，不代表生产实现或实体触屏验收。

**多人席位滚动（本次补充）。** 取消溢出列表的强制居中；少量成员利用首尾自动外边距居中，人数超过可见宽度时自动从首位开始排布。横屏不再隐藏第四位及之后的成员。列表可横向滚轮或触屏滑动，滚动到两端时首位、末位均完整可见；设计稿在溢出时提供悬停翻页箭头，到达边界即隐藏对应方向。交互稿的「多人席位」展示 20 人；`people-checks.json` 覆盖六种尺寸及首尾可达性。

现有课堂另有局部滚动修复（不代表整套新设计已实现）：`classroom-classin.css` 修复居中溢出，允许触屏横向滚动覆盖席位拖拽的 `pan-y` 声明。实际 ClassroomV3 本地替身验证覆盖 25 位成员、五种尺寸、横向滚轮、模拟原生触屏、无误排序/聚焦、RTL 和少人数居中；证据位于 `../classroom-stage-scroll-2026-10-25/stage-scroll-checks.json`。已先复现原问题：滚动起点为 0 时首位 x=-964px，视口起点约 38px。局部修复仅涉及 14 行 CSS，本次无新增 TSX 运行时改动；协调方报告 494 项单元测试通过。尚未部署或在真实微信设备验收。

**角色与危险状态。** 原型提供教师/学生展示变体；结束课程、延时、录制及部分课堂管理入口按角色展示。此处仅表达界面权限意图；原型未接入服务端，现有产品权限不在本次设计验证范围。离开、结束课堂、清空白板、撤回消息先出现后果说明与取消/确认；结束课堂使用危险色，学生界面不展示结束入口。成员下台等其他菜单项仅为演示，实施时按现有课堂权限接入。

**评审与证据边界。** 最终独立评审结论为「Ship as a design draft」，范围仅限此设计稿，无待处理的实质性发现。初次评审查看全部 15 张截图与原型/几何证据；修正后复核更新源码及手机、横屏、悬停、人物操作重截图，不构成新一轮全产品验收。`index.html` 是评审入口，`prototype.html` 提供可交互演示；`review-checks.json` 记录 15 个视口/状态截图、几何检查与少量原型交互检查。截图覆盖安静态、聊天、同传、悬停、设置、更多、人物操作、网络异常以及桌面/超宽/紧凑/手机/横屏/深色变化；记录中页头与页面均无横向溢出。

`design-detector.json` 保留修正前的诊断快照：69 项（20 项 warning、49 项 advisory），不是最终阻塞项计数。两项机械问题已修复并经评审复核：原 9/10px 功能文字提升至至少 11px；评审画廊悬停文字改为 `#20242b`、背景为 `#e9ebef`。与视频画面构图、裁切及中英/代码字体有关的上下文警告经评审接受。`render.cjs` 另有角色断言，验证学生菜单隐藏结束、延时、录制及教师摄像头管理入口；这些只是独立原型内的展示检查。

**多人席位专项复核。** 独立评审对本次补充给出「Ship — design draft only; no material findings」。新增证据为 `people-checks.json` 的 20 人、六种尺寸检查及 `people-first.png`、`people-last.png`、`phone-people-last.png`、`landscape-people-last.png` 四张截图；与初始 15 张截图、分隔线 4 张截图分开记录。`people-detector.json` 为 55 项（7 项 warning、48 项 advisory），沿用已接受的摄像头内距、刻意裁切与系统字体上下文，无新类别；该数字不是阻塞计数。现有课堂 CSS 修复的本地组件回归是另一组证据，不代表整套新视觉或生产验收。

**分隔线专项复核。** 独立完成评审另就本次宽度调节补充给出「Ship — design draft only; no material issues」。范围为更新源码、`resize-checks.json` 与四张新截图：`desktop-resize-hover.png`、`desktop-resize-limit.png`、`compact-resize-limit.png`、`landscape-resize-limit.png`；这些证据与原有 15 张截图及 `review-checks.json` 分开记录。实际鼠标拖拽等检查通过，只证明独立原型中的交互。`resize-detector.json` 单次诊断记录 55 项（7 项 warning、48 项 advisory）；7 项均属已接受的摄像头画面内距、刻意裁切及系统字体上下文警告，不表示清除了新的阻塞项，也不构成全产品复验。

本设计稿中的课堂人物、媒体、课件、消息、翻译、网络状态和计时均为示例或模拟内容。发送、录制、延时、设备切换、AI 助教等交互不代表已接通真实服务。该评审不构成应用集成、生产行为、真实音视频、浏览器触摸或实体设备验收，也不表示用户已经选定此方案。

**现存文档差异，未修复。** 根 `DESIGN.md` 使用带编号的旧章节结构，缺少当前 document 参考规定的独立 Layout / Shapes 章节；`.impeccable/design.json` 当前不存在。`PRODUCT.md` 提及 Outfit/Inter，而 `DESIGN.md` 字体令牌采用系统字体。上述状态先于本次提案存在，本次只记录，不将局部稿件升级为全局规范。

**共享＋人像（2026-10-25 增量）。** 本次只扩展独立设计稿；没有将本地合成、订阅控制接入真实课堂。评审入口默认展示此模式，也保留原「默认」安静态。教师点击底部共享图标可选「仅共享／共享＋人像」，共享中可切换模式、选择四角人像位置或停止。设置和停止图标在舞台悬停、聚焦时出现；触屏直接可见。学生界面仅观看，不展示教师合成控制。

- 合成区域使用固定 1920×1080 的示意坐标，等比缩放到可用舞台，手机同样观看整张合成画面；它是 HTML 设计模拟，不是正在编码或推送的视频。
- 老师原席位保留相同身份、头像、姓名和发言状态，画面替换为「正在共享」。共享内才显示老师人像，避免上下两个相同摄像头画面。开始／停止共享不增加或删除该身份席位。
- 停止共享后恢复老师原摄像头席位；若此前主动关闭摄像头，保持关闭。共享中关闭老师摄像头时隐藏人像小窗，不中断共享。学生自己的摄像头开关不改变老师人像。
- 设计状态标识老师视频为 `composite-only`；停止后恢复 `camera`。这只是订阅意图的模拟标识，不表示 Agora 已取消或恢复订阅。
- 严格保持 Full HD 预算时，1080p 合成流已经占满预算。本稿保留其他成员的头像席位、姓名和发言，使用视频暂停图标表达其视频暂缓接收，悬停／聚焦可读原因；停止共享后移除此预算暂停状态。20 人场景保留全部成员并可滚动。若后续要求同时接收其他人的动态视频，需要降低合成分辨率，或允许更高档位；本稿不作同时保持1080p、多路动态视频与Full HD费用的承诺。

`share-checks.json` 记录 10 张新增截图，覆盖超宽、桌面、紧凑、学生手机、小手机、横屏多人、设置和停止恢复；检查页面无横向溢出、16:9画面边界、图片加载、角色控制、成员保留及模拟状态。按钮交互另验证模式进入/退出、人像左上位置、摄像头关闭、切换仅共享和停止恢复。没有实测合成性能、后台恢复、RTC 收发、真实账单或实体设备。

**示例图片来源。** 新增的教师照片仅用于设计演示，不是 Will 老师真实照片：Vitaly Gariev / Unsplash，https://unsplash.com/photos/smiling-man-with-glasses-in-front-of-chalkboard-WzVIUgKTF-8 ，本地缓存 `presenter-demo.jpg`；正式实施应使用分享人的摄像头与账户头像。

**共享增量复核修正。** 显示教师照片时隐藏占位字母，关闭摄像头才恢复占位。共享舞台减少多余的固定留白，并提供直接可见的放大图标；放大时收起页头、席位、侧栏与底部工具，退出恢复此前侧栏。横屏学生示例的共享宽度由约267px放大至约601px，见 `share-landscape-expanded.png`；手机竖屏的横向共享仍受物理宽度限制，教学阅读宜横屏观看。上述全屏式展示仅为页面内放大，不申请系统全屏。

独立评审确认停止占位与横屏放大问题已解决，并发现放大按钮的 CSS 特异性覆盖。已按其建议将规则改为 `.share-controls .icon.share-expand`，并在放大前后断言计算样式 `opacity=1`；10张交互稿截图已同步更新。静态检测为50项（6 warning / 44 advisory），仍为原有画面裁切、摄像头内距与字体上下文类别。
