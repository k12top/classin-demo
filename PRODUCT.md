# Product

## Register

product

## Users
- **Teachers**: Instructors setting up live courses, organizing student lists and groups, assigning courseware materials, and managing live whiteboard/video rooms.
- **Students**: Learners viewing upcoming and finished class schedules, requesting leaves (cancelled status), entering classrooms using passcodes or share-links, and submitting feedback/remarks.

## Product Purpose
An online interactive virtual classroom workspace powered by Agora Edu SDK and Casdoor SSO authentication, designed to make real-time audio/video lecturing and interactive whiteboard activities seamless, accessible, and fast.

## Brand Personality
- **Apple-like Craft**: Crisp, clean, minimalist layout with high contrast, elegant typography (Outfit/Inter), and spacious, breathable padding.
- **Trustworthy & Educational**: Warm but professional visual accents, clear state statuses, and reassuring loading states.
- **Breathable & Delightful**: Subtle scale transitions, glassmorphic accents where meaningful, and soft borders that define a modern, human interface.

## Anti-references
- **Harsh Neon Clutter**: Multi-gradient borders, excessive neon glows, and dark-mode-only hard contrasts.
- **Stripe/Gradient slop**: Repeating linear stripe patterns and gradient text.
- **Dense/Cramped Lists**: Layouts with narrow margins that feel crowded and leave no room for text hierarchy.

## Design Principles
- **Clarity Over Clutter**: Ensure each screen has a single clear primary CTA, and simplify navigation steps.
- **Context Preservation**: Prevent full-page jolts by keeping layouts stable and smooth.
- **Absolute Accessibility**: High-contrast text, keyboard-friendly gates, and visible focus rings.
- **Timezone Transparency**: Make class start times clear across diverse international student locations.

## Accessibility & Inclusion
- Contrast ratio >= 4.5:1 for body and placeholder text.
- Support browser/locale native date representations and safe timezone conversions.
- Respect reduced motion settings for all animations.
